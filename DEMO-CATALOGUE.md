# Fruits & Vegetables Catalogue Demo

This branch is an isolated visual demo for the Fruits and Vegetables catalogues.

- Branch: `demo-fruits-vegetables-catalogue`
- Production branch: `main` (unchanged)
- Scope: `/products/fruits/` and `/products/vegetables/`
- No production deployment is implied by this branch.

## Preview deployment

Deploy this branch to a separate Cloudflare Worker/preview project. Do not attach it to the production `emperio-tiss.com` Worker or production routes.

Suggested preview worker name: `emperio-tiss-catalogue-demo`
