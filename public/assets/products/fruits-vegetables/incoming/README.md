# Incoming — Frutas y Hortalizas

Add product photographs here using the same principle as the seafood catalogue.

## Naming convention

Use the product identifier as the base name:

- `Naranja.jpg`
- `Naranja(1).jpg`
- `Tomate.jpg`
- `Tomate(1).jpg`

The first image becomes the primary catalogue image; additional numbered images become the product gallery.

## Image characteristics

- JPG, JPEG, PNG or WEBP
- Product-focused, high-resolution photography
- Prefer consistent landscape framing (4:3 works best)
- No text, logos or promotional overlays inside the photograph
- Keep the original image quality; do not manually resize for the website

## Automatic update

The fruits & vegetables catalogue should read this folder through its image manifest. When new photographs are added, the corresponding product image mapping can be regenerated without changing the catalogue layout or product data.

Do not place CSS, HTML or JavaScript in this folder. It is exclusively for incoming product photography.
