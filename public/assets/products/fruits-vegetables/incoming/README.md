# Fruits & Vegetables image intake

Add Fruits & Vegetables catalogue images to this folder.

## Naming

Use the existing product ID as the filename base:

- `naranja.jpg`
- `naranja-2.jpg`
- `naranja-3.jpg`
- `tomate.jpg`
- `tomate-2.jpg`

The automatic sync groups numbered variants (`-2`, `-3`, etc.) with the same product.

## Image standard

For the catalogue, use a clean product photograph with the subject clearly visible and enough surrounding space for the existing catalogue frame. JPG, JPEG, PNG and WebP are accepted. Prefer high-resolution product-focused images without text, logos or promotional overlays.

## Automatic update

When an image is added, renamed or removed in this folder, the catalogue image manifest can be regenerated by the website's image-sync workflow. The Fruits & Vegetables catalogue can then pick up the new image automatically on deployment.

This folder controls **images only**. Product name, variety, scientific name, category, origin, availability and other technical characteristics remain controlled by the catalogue data and are not guessed from a photograph.
